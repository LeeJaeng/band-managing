# 페이지 구조

Nuxt 3 file-based routing. 모든 페이지는 `web/pages/`에 위치.

## `/` (index.vue) — 홈

방(세션) 생성 페이지.

- 방 이름 입력
- 파트 목록 커스터마이징 (기본 10개, 추가/삭제 가능)
- 이전 세션 재개 (localStorage 기반)
- 생성 시: POST /teams → POST /sessions → /session/:id로 이동

## `/join?sid=` (join.vue) — 입장

세션 참여 페이지.

- 세션 ID 입력 (또는 쿼리 파라미터로 전달)
- 사용자 이름 입력
- 파트 선택 (서버에서 세션별 파트 목록 로드)
- 입장 시: POST /sessions/:id/join → /session/:id로 이동

## `/session/[id]` (session/[id].vue) — 세션 메인

핵심 페이지. 실시간 브로드캐스트 및 관리.

**쿼리 파라미터**: `pid`, `name`, `part`, `role`

### 공통 기능
- 세션 정보 표시
- 참여자 목록 (실시간 업데이트)
- 브로드캐스트 수신 → 오버레이 표시
- 이벤트 로그 (최신 50개)
- 초대 링크 복사

### LEADER 전용
- 브로드캐스트 메시지 전송
- 프리셋 관리 (추가/수정/삭제)
- 멤버 권한 관리 (브로드캐스트 허용/차단)

### MEMBER (권한 있음)
- 브로드캐스트 메시지 전송
- 프리셋 사용 (읽기 전용)
