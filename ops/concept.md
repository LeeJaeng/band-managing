# 서비스 개념

## 무엇을 위한 서비스인가

**Band Managing**은 교회 밴드(찬양팀) 운영을 위한 실시간 커뮤니케이션 도구입니다.

예배나 찬양 중에 리더가 밴드 멤버들에게 실시간으로 지시 사항을 전달할 수 있습니다. 화면에 오버레이로 메시지가 표시되어, 멤버들이 별도의 채팅 앱을 확인하지 않아도 즉시 내용을 확인할 수 있습니다.

## 핵심 가치

- **즉시성** — WebSocket 기반 실시간 전달, 지연 없이 메시지가 화면에 표시
- **단순함** — 별도 회원가입 없이 방 생성 → 링크 공유 → 바로 사용
- **파트 구분** — 보컬, 피아노, 기타, 드럼 등 악기별 역할 구분
- **권한 관리** — 리더만 메시지를 보내거나, 특정 멤버에게 권한 부여 가능

## 사용 시나리오

1. 예배 전: 리더가 세션(방)을 생성하고 초대 링크를 밴드 멤버들에게 공유
2. 예배 중: 리더가 "다음 곡: OOO", "키 변경: C→D" 등의 메시지를 브로드캐스트
3. 멤버 화면: 메시지가 오버레이로 표시되어 즉시 확인 가능
4. 프리셋 활용: 자주 사용하는 메시지를 미리 저장해두고 원클릭으로 전송

## 대상 사용자

- 교회 찬양팀 리더
- 밴드 멤버 (악기 연주자, 보컬, 음향/영상 담당)
