# 관리자 기능

## 설계 원칙

> 관리자가 수동으로 하는 모든 작업은 API 기반으로 구현하여, 추후 자동화로 전환 가능하게 한다.

## 현재 구현된 기능

### 1. 크롤링 채널 관리
- 채널 등록: 유튜브 URL만 입력 → [자동입력]으로 이름+채널ID 자동 변환
- 채널 수정 (이름, URL, 채널ID, 신뢰도)
- 채널 활성화/비활성화
- 채널 삭제 (관련 로그/검증큐 정리)

### 2. 크롤링 실행
- 개별 채널 크롤링 / 전체 크롤링 (활성 채널만)
- **세트리스트 크롤링**: 예배 실황 영상 description의 타임스탬프+곡명+키 자동 파싱 → 곡/키 자동 등록 + 타임스탬프 레퍼런스 생성
- 크롤링 결과 alert 표시 (영상 수, 레퍼런스 추가 수, 신규 곡 수)
- 크롤링 로그 확인 (상태, 에러 메시지)

### 3. 검증 큐
- 크롤링 봇이 자동 매칭 못한 영상 목록
- 유사곡 후보 자동 검색/표시
- [이 곡에 추가] / [새 곡으로 등록] / [거부]
- **자동 승인**: 블랙리스트(설교/축도/큐티/브이로그 등) + 문장형 휴리스틱(`...습니다/입니다`)으로 곡이 아닌 항목을 걸러낸 뒤 일괄 승인
- **제목 재파싱**: parser 개선 후 PENDING 항목의 `parsed_song_title`을 일괄 재계산
- 일괄 처리 / 내보내기(JSON)

### 4. 곡 DB 관리 (곡 DB 페이지)
- 곡 목록 (팀별 레퍼런스 태그 — `refs_by_team` 표시), 100개씩 더보기 페이지네이션
- 곡 검색 (제목/가사), 키/빠르기/팀(채널) 필터
- 곡 수동 등록 / 편집 / 삭제 / 일괄 편집 (키, tempo)
- 레퍼런스/악보 관리

### 4-1. 중복 곡 정리
- `GET /api/admin/songs/duplicate-candidates` — 정규화 제목(괄호/공백/구두점 제거)으로 중복 후보 그룹화
- 정확 일치 + 접두 일치(4글자 이상)를 Union-Find로 묶음
- 모달에서 그룹별 미리보기 → 남길 곡 선택(라디오) → 최종 제목 직접 수정 가능 → "이 그룹 병합"
- 병합 시 source 곡들의 레퍼런스/악보/콘티 항목이 target으로 이동되고 source는 삭제됨

## Phase 2 구현 완료

### 5. 인증 + 역할 구분 ✅
- 아이디/비번 로그인 (JWT, bcrypt)
- 역할: ADMIN / MEMBER
  - **관리자**: 크롤링 채널/실행, 검증 큐, 곡 DB 편집/삭제/병합, 유저 등록 곡 정제, 팀 멤버 관리
  - **일반 사용자**: 곡 검색/열람, 콘티 작성/편집, 곡 직접 등록
- 관리자 라우트 보호 (/admin/*), 쓰기 API 인증 필수, 읽기 API 공개

### 6. 유저 등록 곡 정제 큐 ✅
- 인도자가 콘티 작성 중 없는 곡 직접 등록 → 바로 사용 가능 (source=USER)
- 관리자 페이지에서 유저 등록 곡 목록 확인 → 승인(source=MANUAL) 또는 삭제
- 관리자 정제 작업: 제목 정규화, 중복 곡 병합, 키/가사/레퍼런스 보강
- (장기) AI 자동 정제로 전환 가능

### 7. 팀 멤버 관리 ✅
- 멤버 등록 (이름, 포지션), 활성화/비활성화, 수정, 삭제
- 포지션: 피아노, 신디, 드럼, 베이스, 보컬, 기타, 어쿠스틱, 기타(일렉)
- 콘티 작성 시 멤버 배정에 사용

### 자동화 전환
| 수동 (현재) | 자동화 (추후) |
|-----------|-------------|
| 채널 등록 버튼 | 인기 채널 자동 추천 |
| 크롤링 수동 실행 | 주기적 자동 크롤링 (cron) |
| 검증 큐 수동 승인 | AI 자동 매칭 |
| 유저 등록 곡 수동 정제 | AI 자동 정제 (제목 정규화, 중복 판단) |
