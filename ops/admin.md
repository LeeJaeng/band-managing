# 관리자 기능

## 설계 원칙

> 관리자가 수동으로 하는 모든 작업은 API 기반으로 구현하여, 추후 자동화로 전환 가능하게 한다.

## 현재 구현된 기능

### 1. 크롤링 채널 관리
- 채널 등록: 유튜브 URL만 입력 → [자동입력]으로 이름+채널ID 자동 변환
- 채널 수정 (이름, URL, 채널ID, 신뢰도)
- 채널 활성화/비활성화
- 채널 삭제 (관련 로그/검증큐 정리)

### 2. 크롤링 실행
- 개별 채널 크롤링
- 전체 채널 크롤링 (활성 채널만)
- 크롤링 결과 alert 표시 (영상 수, 레퍼런스 추가 수)
- 크롤링 로그 확인 (상태, 에러 메시지)

### 3. 검증 큐
- 크롤링 봇이 자동 매칭 못한 영상 목록
- 유사곡 후보 자동 검색/표시
- [이 곡에 추가] → 기존 곡에 레퍼런스 매칭
- [새 곡으로 등록] → 새 곡 생성
- [거부] → 무시
- 유튜브 영상 링크로 직접 확인 가능

### 4. 곡 DB 관리 (곡 DB 페이지)
- 곡 목록 (레퍼런스 수 표시)
- 곡 검색 (제목/가사)
- 곡 수동 등록 (제목, 키, 가사, 레퍼런스)
- 곡 편집 (제목, 키 복수 선택, 가사/송폼)
- 곡 삭제
- 레퍼런스 추가/삭제
- 악보 관리

## 추후 확장

### 사용자 관리 (Phase 2)
- 회원가입/로그인
- 팀 생성/관리
- 멤버 초대/권한

### 자동화 전환
| 수동 (현재) | 자동화 (추후) |
|-----------|-------------|
| 채널 등록 버튼 | 인기 채널 자동 추천 |
| 크롤링 수동 실행 | 주기적 자동 크롤링 (cron) |
| 검증 큐 수동 승인 | AI 자동 매칭 |
