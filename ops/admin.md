# 관리자 기능

## 설계 원칙

> 관리자가 수동으로 하는 모든 작업은 API 기반으로 구현하여, 추후 자동화로 전환 가능하게 한다.

## MVP 관리자 기능

### 1. 크롤링 관리
- 사역팀 채널 등록/수정/삭제/활성화
- 수동 크롤링 실행 (특정 채널 or 전체)
- 크롤링 상태 대시보드 (마지막 실행, 수집 건수, 에러)
- 크롤링 로그 확인

### 2. 곡 DB 관리
- 곡 목록 조회 (검색, 필터)
- 곡 수동 등록 (제목, 가사, 키)
- 곡 수정/삭제
- 곡 병합 (중복 곡 합치기)
- 레퍼런스 관리 (추가/삭제/신뢰도 설정)
- 악보 업로드 (PDF/이미지, 레퍼런스 연결)

### 3. 검증 큐
- 크롤링 봇이 자동 매칭하지 못한 곡 목록
- 관리자가 확인 후 승인/수정/삭제
- 중복 의심 곡 확인

## 추후 확장

### 사용자 관리 (Phase 2)
- 회원가입/로그인
- 팀 생성/관리
- 멤버 초대/권한

### 자동화 전환 예시

| 수동 (MVP) | 자동화 (추후) |
|-----------|-------------|
| 채널 등록 버튼 | 인기 채널 자동 추천 |
| 크롤링 수동 실행 | 주기적 자동 크롤링 (cron) |
| 검증 큐 수동 승인 | AI 자동 매칭 (유사도 기반) |
| 가사 수동 입력 | 유튜브 설명/자막 자동 추출 |
| 악보 수동 업로드 | AI 채보 자동 생성 |
