# 역할 및 권한 체계

## 역할 (Role)

| 역할 | 부여 조건 | 설명 |
|------|----------|------|
| **LEADER** | 세션 최초 입장자 (방 생성자) | 모든 권한 보유 |
| **MEMBER** | 2번째 이후 입장자 | 제한된 권한 |

## 권한 매트릭스

| 기능 | LEADER | MEMBER (권한 없음) | MEMBER (권한 있음) |
|------|--------|-------------------|-------------------|
| 브로드캐스트 전송 | O | X | O |
| 브로드캐스트 수신 | O | O | O |
| 프리셋 관리 (CRUD) | O | X | X |
| 프리셋 사용 (전송) | O | X | O |
| 멤버 권한 관리 | O | X | X |
| 참여자 목록 확인 | O | O | O |
| 초대 링크 복사 | O | O | O |

## 권한 부여 방식

1. 리더가 세션 내 참여자 목록에서 특정 멤버를 선택
2. 브로드캐스트 권한 토글 (on/off)
3. 변경 사항이 WebSocket을 통해 실시간 반영
4. 서버(DB grants 테이블)에 영구 저장

## 브로드캐스트 권한 검증 흐름

```
POST /broadcasts 요청
  ↓ sender_id로 참가자 조회
  ↓ role == "LEADER" → 허용
  ↓ role == "MEMBER" → grants 테이블 조회
     ├── can_broadcast == true → 허용
     └── can_broadcast == false 또는 없음 → 403 거부
```
