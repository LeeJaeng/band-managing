# 콘티 작성 기능

## 콘티란?

예배 순서에 따른 곡 목록. 인도자가 매주 작성하며, 밴드 멤버들이 이를 보고 연습/준비.

## 콘티 구조

```
콘티
├── 날짜 (2026-04-06)
├── 예배명 ("청년예배", "주일 2부" 등)
├── 작성자
├── 상태 (작성중 / 확정)
├── 사역 멤버 ✅
│    ├── 피아노: 홍길동
│    ├── 신디: 장금이
│    ├── 드럼: 김철수
│    ├── 베이스: 최민수
│    └── 보컬: 이영희, 박지수
└── 곡 목록 (순서)
     ├── 1번곡 → 곡 DB 연결
     ├── 2번곡 → 곡 DB 연결
     ├── 3번곡 → 곡 DB 연결
     ├── 4번곡 → 곡 DB 연결
     ├── 기도곡 → 곡 DB 연결
     └── 헌금송 → 곡 DB 연결
```

## 콘티 항목 (곡 슬롯)

각 슬롯에는:
- 곡 DB에서 검색/선택한 곡이 연결됨
- 슬롯 라벨 (1번곡, 기도곡, 헌금송 등 — 커스텀 가능)
- 사용할 키 (곡 DB의 키가 선입력, 수정 가능)
- 키업 표시 (E→F, E→F→G 등 — "E-F-G" 형태로 저장)
- 선택한 레퍼런스 (여러 레퍼런스 중 이번에 참고할 버전)
- 메모 (자유 텍스트)

## 사용 흐름

```
1. [새 콘티 만들기] → 날짜, 예배명 입력
2. [사역 멤버 배정] → 미리 등록된 멤버 중 포지션별 선택
3. [곡 추가] → 곡 검색 (제목/가사)
4. 검색 결과에서 곡 선택
   → 곡 DB의 키가 자동 선입력 (수정 가능)
   → 키업이 있으면 키 체인으로 입력 (E → F → G)
   → 레퍼런스 선택 (어떤 버전 기준으로 할지)
5. 곡 순서 배치
6. [확정] → 공유
```

## 콘티 편집

- 곡 순서 변경 (위/아래 이동)
- 곡 교체 (다른 곡으로 변경)
- 곡 삭제
- 키 인라인 편집 (클릭하면 키 선택기 열림, 키업 체인 지원)
- 공동 편집: 인도자 외 편집 권한 부여 가능 (추후)

## 콘티 공유 ✅

### 텍스트 복사
카톡/밴드에 바로 붙여넣기 가능한 텍스트 생성:
```
📋 2026.04.06 주일예배 콘티

🎵 사역팀
피아노: 홍길동 | 드럼: 김철수 | 보컬: 이영희, 박지수

🎶 곡 순서
1번곡 | 마른 뼈에 기름부으라 | G → A
2번곡 | 주만 바라볼찌라 | E
기도곡 | 은혜 | D
헌금송 | 감사해 | F

🔗 레퍼런스
1. 마른 뼈에 기름부으라 - https://youtu.be/...
2. 주만 바라볼찌라 - https://youtu.be/...
```

### 링크 공유
- 인증 없이 열리는 읽기 전용 페이지
- 콘티 + 사역멤버 + 레퍼런스 링크
- 모바일 최적화 (예배 중 폰/태블릿으로 확인)
