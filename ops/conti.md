# 콘티 작성 기능

## 콘티란?

예배 순서에 따른 곡 목록. 인도자가 매주 작성하며, 밴드 멤버들이 이를 보고 연습/준비.

## 콘티 구조

```
콘티
├── 날짜 (2026-04-06)
├── 예배명 ("청년예배", "주일 2부" 등)
├── 작성자
├── 상태 (작성중 / 확정)
└── 곡 목록 (순서)
     ├── 1번곡 → 곡 DB 연결
     ├── 2번곡 → 곡 DB 연결
     ├── 3번곡 → 곡 DB 연결
     ├── 4번곡 → 곡 DB 연결
     ├── 기도곡 → 곡 DB 연결
     └── 헌금송 → 곡 DB 연결
```

## 콘티 항목 (곡 슬롯)

각 슬롯에는:
- 곡 DB에서 검색/선택한 곡이 연결됨
- 슬롯 라벨 (1번곡, 기도곡, 헌금송 등 — 커스텀 가능)
- 사용할 키 (곡 DB의 원키와 다를 수 있음)
- 선택한 레퍼런스 (여러 레퍼런스 중 이번에 참고할 버전)
- 메모 (자유 텍스트)

## 사용 흐름

```
1. [새 콘티 만들기] → 날짜, 예배명 입력
2. [곡 추가] → 곡 검색 (제목/가사)
3. 검색 결과에서 곡 선택
   → 해당 곡의 레퍼런스, 키, 가사가 바로 보임
   → 레퍼런스 선택 (어떤 버전 기준으로 할지)
   → 키 설정
4. 곡 순서 배치
5. [확정] → 추후 멤버에게 공유/알림
```

## 콘티 편집

- 곡 순서 변경 (위/아래 이동)
- 곡 교체 (다른 곡으로 변경)
- 곡 삭제
- 공동 편집: 인도자 외 편집 권한 부여 가능 (추후)
