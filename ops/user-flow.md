# 사용자 흐름

## 1. 방 생성 (리더)

```
홈 페이지 (/)
  ↓ 방 이름 입력
  ↓ 파트 목록 설정 (기본 10개, 커스터마이징 가능)
  ↓ [방 만들기] 클릭
  ↓ 자동으로 팀 생성 → 세션 생성 → 입장
세션 페이지 (/session/:id) — LEADER로 입장
```

## 2. 방 입장 (멤버)

```
초대 링크 클릭 → 입장 페이지 (/join?sid=...)
  ↓ 이름 입력
  ↓ 파트 선택
  ↓ [입장] 클릭
세션 페이지 (/session/:id) — MEMBER로 입장
```

## 3. 브로드캐스트 (세션 내)

### 리더 → 멤버
```
리더: 메시지 입력 또는 프리셋 선택 → [전송]
  ↓ POST /broadcasts
  ↓ WebSocket으로 전체 참여자에게 전달
멤버: 화면에 오버레이로 메시지 표시 (설정한 초 후 자동 사라짐)
```

### 프리셋 관리
```
리더: [프리셋 관리] → 제목/내용 입력 → [저장]
  ↓ POST /teams/:id/presets
  ↓ WebSocket으로 PRESETS_UPDATED 알림
리더: 프리셋 버튼 클릭 → 즉시 브로드캐스트
```

### 권한 관리
```
리더: 참여자 목록에서 멤버 선택 → 브로드캐스트 권한 토글
  ↓ POST /sessions/:id/broadcast-permissions
  ↓ WebSocket으로 PERMISSION_UPDATED 알림
```

## 4. 재접속

```
브라우저 새로고침 또는 재방문
  ↓ localStorage에서 세션 정보 복구
  ↓ 홈 페이지에 "진행 중인 세션" 표시
  ↓ 클릭 시 세션 페이지로 복귀
```
