# MVP 정의

## Phase 1 — MVP (현재 구현 완료)

### 1. 곡 DB ✅
- 곡 CRUD (제목, 키 복수 등록, 가사/송폼)
- 레퍼런스 관리 (유튜브 링크, 복수, 추가/삭제)
- 악보 관리 (레퍼런스별 연결)
- 곡 검색 (제목/가사)
- 곡 병합 (중복 처리)
- 곡 삭제 (FK 정리 포함)
- 수동 등록 페이지 (/songs/new)

### 2. 콘티 작성 ✅
- 날짜 + 예배명으로 콘티 생성
- 곡 DB에서 검색 → 콘티에 곡 추가
- 곡 순서 배치, 슬롯 라벨 (1번곡, 기도곡, 헌금송)
- 곡별 키 변경, 메모
- 콘티 확정 (DRAFT → CONFIRMED)

### 3. 크롤링 봇 ✅
- YouTube Data API v3 (playlistItems API)
- 관리자 화면에서 채널 등록 (URL만 넣으면 자동 ID 변환)
- 개별/전체 크롤링 실행
- 20분 초과 영상 무시
- 예배실황/연주/inst/MR 등 키워드 필터링
- 곡 매칭 → 레퍼런스 추가 or 검증 큐

### 4. 관리자 화면 ✅
- 채널 CRUD (URL 입력 → 자동 채널 ID/이름 변환)
- 크롤링 실행 + 결과 표시
- 크롤링 로그 확인
- 검증 큐 (유사곡 후보 자동 표시, 기존곡 매칭 or 새곡 등록)

### 5. 인프라 ✅
- Docker Compose (nginx + web + api + db)
- GitHub Actions 자동 배포 (main push)
- Nginx 캐시 제어 (배포 시 자동 갱신)
- 45개 백엔드 테스트
