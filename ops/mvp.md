# MVP 정의

## Phase 1 — MVP (현재 목표)

### 1. 곡 DB
- 크롤링 봇으로 CCM/찬양곡 자동 수집 (유튜브)
- 신뢰 사역팀 채널 우선 수집
- 곡 정보: 제목, 레퍼런스(유튜브, 복수), 키, 가사
- 악보: 수동 업로드 (PDF/이미지), 레퍼런스별 연결

### 2. 콘티 작성
- 날짜 + 예배명으로 콘티 생성
- 곡 DB에서 검색 → 콘티에 곡 추가
- 곡 순서 배치 (드래그 또는 순서 변경)
- 곡별 메모 (키 변경, 특이사항 등)

### 3. 관리자 화면
- 크롤링 대상 채널 관리 (추가/삭제/활성화)
- 크롤링 상태 모니터링
- 곡 DB 관리 (수동 등록/수정/삭제/병합)
- 레퍼런스 품질 관리 (신뢰도 표시 등)
- **설계 원칙**: 관리자가 수동으로 하는 모든 작업은 추후 자동화 가능하도록 API 기반으로 구현

---

## Phase 2 — 확장 (추후)

- 회원가입 / 팀 관리
- 팀별 콘티 공유
- 사역팀 배정 + 알림 (밴드마스터 우선 알림)
- 악보 뷰어 (메모, 펜슬)
- AI 기반 악보 자동 생성 (편곡별)

## Phase 3 — 풀 기능 (장기)

- 일정 관리 + 캘린더
- 채팅
- 사진첩
- 공동체 기능 (랜덤 조, 밥 메뉴 등)
- 네이티브 앱 (iOS/Android)
- 푸시 알림
