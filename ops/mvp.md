# MVP 정의

## Phase 1 — MVP (현재 구현 완료)

### 1. 곡 DB ✅
- 곡 CRUD (제목, 키 복수 등록, 가사/송폼)
- 레퍼런스 관리 (유튜브 링크, 복수, 추가/삭제)
- 악보 관리 (레퍼런스별 연결)
- 곡 검색 (제목/가사)
- 곡 병합 (중복 처리)
- 곡 삭제 (FK 정리 포함)
- 수동 등록 페이지 (/songs/new)

### 2. 콘티 작성 ✅
- 날짜 + 예배명으로 콘티 생성
- 곡 DB에서 검색 → 콘티에 곡 추가
- 곡 순서 배치, 슬롯 라벨 (1번곡, 기도곡, 헌금송)
- 곡별 키 변경, 메모
- 콘티 확정 (DRAFT → CONFIRMED)

### 3. 크롤링 봇 ✅
- YouTube Data API v3 (playlistItems API)
- 관리자 화면에서 채널 등록 (URL만 넣으면 자동 ID 변환)
- 개별/전체 크롤링 실행
- 20분 초과 영상 무시
- 예배실황/연주/inst/MR 등 키워드 필터링
- 곡 매칭 → 레퍼런스 추가 or 검증 큐

### 4. 관리자 화면 ✅
- 채널 CRUD (URL 입력 → 자동 채널 ID/이름 변환)
- 크롤링 실행 + 결과 표시
- 크롤링 로그 확인
- 검증 큐 (유사곡 후보 자동 표시, 기존곡 매칭 or 새곡 등록)

### 5. 인프라 ✅
- Docker Compose (nginx + web + api + db)
- GitHub Actions 자동 배포 (main push)
- Nginx 캐시 제어 (배포 시 자동 갱신)
- 45개 백엔드 테스트

## Phase 2 — 팀 운영 + 공유 (구현 완료)

### 1. 인증 + 역할 구분 ✅
- 아이디/비번 로그인 (JWT, passlib+bcrypt, python-jose)
- 역할: ADMIN / MEMBER
  - **관리자**: 크롤링 채널/실행, 검증 큐, 곡 DB 편집/삭제/병합, 유저 등록 곡 정제, 팀 멤버 관리
  - **일반 사용자**: 곡 검색/열람, 콘티 작성/편집, 곡 직접 등록
- 관리자 라우트 보호 (/admin/*), 콘티/곡 쓰기에 인증 필수
- 읽기 API는 공개 (콘티 공유 링크 지원)

### 2. 팀 멤버 관리 ✅
- 멤버 등록 (이름, 포지션: 피아노/신디/드럼/베이스/보컬/기타/어쿠스틱/기타(일렉))
- 활성화/비활성화, 수정, 삭제

### 3. 콘티에 사역 멤버 배정 ✅
- 콘티에 "사역팀" 섹션 — 칩 UI로 포지션+이름 표시
- 미리 등록된 멤버 중 선택, 이미 배정된 멤버 자동 필터링

### 4. 콘티 공유 ✅
- **텍스트 복사**: 카톡/밴드에 바로 붙여넣기 (사역팀 + 곡 순서 + 키업 + 레퍼런스)
- **링크 복사**: 인증 없이 열리는 읽기 전용 페이지 (/conti/share/{id})
- Nuxt Layout 분리 (default: 네비 포함, share: 최소 레이아웃)

### 5. 키 UX 개선 ✅
- 인라인 키 편집 (클릭하면 키 선택기 열림)
- 키업 체인: "E-F-G" 저장, "E → F → G" 표시
- 곡 추가 시 DB 키 자동 선입력
- 자주 쓰는 키 우선 표시, "더보기"로 기타/마이너

### 6. 유저 곡 등록 + 관리자 정제 ✅
- 일반 유저 곡 등록 → source=USER, 바로 사용 가능
- 관리자 등록 → source=MANUAL
- 관리자 페이지에서 유저 등록 곡 목록 확인 + 승인/삭제
- 곡은 팀 공유 자산 (개인 소유 X)

### 7. 악보
- 현재: 외부 링크(구글 드라이브 등) 등록으로 충분
- 추후: PDF 업로드 + 뷰어 (S3 스토리지, 인앱 뷰어)

## Phase 3 — 풀 기능 (장기)

- 악보 뷰어 (인앱 PDF 뷰어, 메모/펜슬)
- 일정 관리 + 캘린더
- 알림 (밴드마스터 우선 알림)

- 푸시 알림
- AI 자동 매칭 (유저 등록 곡 자동 정제, 제목 정규화, 중복 판단)
