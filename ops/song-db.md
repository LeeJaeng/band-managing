# 곡 DB 및 크롤링

## 곡 데이터 구조 (현재)

```
곡 (Song)
├── 제목
├── 키 (복수, JSON 배열) ["A", "G", "Bb"]
├── 가사 / 송폼 (텍스트, [Verse]/[Chorus] 구분)
├── 레퍼런스 (1:N)
│    ├── 유튜브 URL + 영상 ID
│    ├── 영상 제목
│    ├── 썸네일
│    ├── 키 (해당 버전)
│    ├── 신뢰도 (HIGH/MEDIUM/LOW, 채널 기반)
│    ├── 출처 (CRAWL/MANUAL)
│    └── 연결된 채널
└── 악보 (1:N)
     ├── 파일 URL
     ├── 파일 타입 (PDF/IMAGE)
     ├── 연결된 레퍼런스 (어떤 편곡 기준)
     └── 업로드자
```

## 곡 관리 기능
- 곡 CRUD (제목, 키 복수, 가사/송폼)
- 키 입력 개선: 자주 쓰는 키(C,D,E,F,G,A,Bb,B) 우선 표시, 더보기로 기타/마이너
- 레퍼런스 추가/삭제 (유튜브 URL, 키, 수동 등록)
- 악보: 외부 링크 등록 (추후 파일 업로드 + 뷰어)
- 곡 병합 (중복 곡 합치기)
- 곡 삭제 시 conti_items/review_queue FK 자동 정리

## 곡 등록 흐름 (Phase 2)

```
크롤링 봇 등록 (source=CRAWLED)  →  곡 DB에 자동 등록
관리자 수동 등록 (source=MANUAL)  →  곡 DB에 직접 등록
인도자 직접 등록 (source=USER)   →  곡 DB에 등록 + 바로 사용 가능
                                    └→ 관리자 정제 큐에 올라감
```

- 곡은 팀 공유 자산 (개인 소유 X)
- 인도자 등록 곡은 정보가 불완전할 수 있음 → 관리자가 정제
- 정제: 제목 정규화, 중복 병합, 키/가사/레퍼런스 보강

## 크롤링 흐름

### 채널 등록
1. 관리자 페이지에서 유튜브 URL 입력
2. [자동입력] → YouTube channels API로 @handle → UC... 변환 + 채널 이름 자동 채움
3. 신뢰도 설정 (HIGH/MEDIUM/LOW)

### 크롤링 실행
1. 개별 또는 전체 채널 크롤링 (수동 트리거)
2. playlistItems API로 영상 수집
3. 필터링: 10분 초과, 예배실황, 연주/inst/MR, 합쳐진 곡 (+, 메들리)
4. 곡 제목 파싱: 패턴 제거 + 사역팀 이름 제거
5. 곡 매칭 → 레퍼런스 추가 or 검증 큐

### 검증 큐
- 크롤링 봇이 자동 매칭 못한 영상
- 유사곡 후보 자동 검색/표시 (파싱된 제목으로 DB 검색)
- [이 곡에 추가] → 기존 곡에 레퍼런스 매칭
- [새 곡으로 등록] → 새 곡 생성 + 레퍼런스
- [거부] → 무시
- 유튜브 링크로 직접 확인 가능

## 자동화 로드맵
```
현재 (MVP)              → 추후 자동화
───────────────────────────────────
관리자가 채널 등록        → 인기 채널 자동 추천
크롤링 수동 실행         → 주기적 자동 크롤링 (cron)
검증 큐 수동 승인        → AI 자동 매칭 (유사도 기반)
가사 수동 입력           → 유튜브 자막 자동 추출
악보 수동 업로드         → AI 채보 자동 생성
```
