# 곡 DB 및 크롤링

## 곡 데이터 구조 (현재)

```
곡 (Song)
├── 제목
├── 키 (복수, JSON 배열) ["A", "G", "Bb"]
├── 빠르기 (tempo: FAST / SLOW / 미분류)
├── 가사 / 송폼 (텍스트, [Verse]/[Chorus] 구분)
├── 레퍼런스 (1:N)
│    ├── 유튜브 URL + 영상 ID
│    ├── 영상 제목
│    ├── 썸네일
│    ├── 키 (해당 버전)
│    ├── 신뢰도 (HIGH/MEDIUM/LOW, 채널 기반)
│    ├── 출처 (CRAWL/MANUAL)
│    └── 연결된 채널
└── 악보 (1:N)
     ├── 파일 URL
     ├── 파일 타입 (PDF/IMAGE)
     ├── 연결된 레퍼런스 (어떤 편곡 기준)
     └── 업로드자
```

## 곡 관리 기능
- 곡 CRUD (제목, 키 복수, 빠르기, 가사/송폼)
- 키 입력 개선: 자주 쓰는 키(C,D,E,F,G,A,Bb,B) 우선 표시, 더보기로 기타/마이너
- 레퍼런스 추가/삭제 (유튜브 URL, 키, 수동 등록)
- 악보: 외부 링크 등록 (추후 파일 업로드 + 뷰어)
- 곡 필터: 키별 / 빠르기별 / 팀(채널)별 / 키 없음 / 빠르기 없음 필터링
- 페이지네이션: 100개씩 더보기 (총 N곡 표시)
- 팀별 레퍼런스 표시: 각 곡 카드에 `{팀명: N개}` 태그로 출처 분포 표시 (refs_by_team)
- 일괄 편집: 선택된 곡 여러 개에 키 추가 / 빠르기 일괄 설정
- 곡 병합: 멀티소스(`source_ids[] + target_id`) + target 제목 수정 옵션
- 중복 곡 정리: 정규화 제목(괄호/공백 무시) + 접두 일치 그룹화 → 그룹별 미리보기/병합
- 곡 삭제 시 conti_items/review_queue FK 자동 정리

## 곡 등록 흐름 (Phase 2)

```
크롤링 봇 등록 (source=CRAWLED)  →  곡 DB에 자동 등록
관리자 수동 등록 (source=MANUAL)  →  곡 DB에 직접 등록
인도자 직접 등록 (source=USER)   →  곡 DB에 등록 + 바로 사용 가능
                                    └→ 관리자 정제 큐에 올라감
```

- 곡은 팀 공유 자산 (개인 소유 X)
- 인도자 등록 곡은 정보가 불완전할 수 있음 → 관리자가 정제
- 정제: 제목 정규화, 중복 병합, 키/가사/레퍼런스 보강

## 크롤링 흐름

### 채널 등록
1. 관리자 페이지에서 유튜브 URL 입력
2. [자동입력] → YouTube channels API로 @handle → UC... 변환 + 채널 이름 자동 채움
3. 신뢰도 설정 (HIGH/MEDIUM/LOW)

### 크롤링 실행
1. 개별 또는 전체 채널 크롤링 (수동 트리거 / 일일 cron)
2. playlistItems API로 영상 수집 (증분, 이미 본 영상 만나면 조기 종료)
3. 필터링: 10분 초과/60초 이하, 예배실황, 연주/inst/MR, 합쳐진 곡 (+, 메들리)
4. 곡 제목 파싱: 패턴 제거 + 팀명 제거 + 인도자 메타 제거 + 영문 부제 제거
5. 매칭 성공 → 레퍼런스 추가 + description에서 가사/악보 링크/키 보강
6. 매칭 실패 → 검증 큐

### 세트리스트 크롤링
- 별도 엔드포인트 (`/api/admin/crawl-setlists/...`)
- 예배 실황 영상 description에서 타임스탬프+곡명+키 일괄 추출
- 곡 자동 등록 + 타임스탬프 레퍼런스(`{video_id}@{seconds}`) 생성
- 검증 큐 거치지 않음 (description이 곡 목록 자체이므로)

### 검증 큐
- 크롤링 봇이 자동 매칭 못한 영상
- 10개씩 페이지네이션, 처리 시 자동 채우기
- 유사곡 후보 자동 검색/표시 (파싱된 제목으로 DB 검색)
- [이 곡에 추가] / [새 곡으로 등록] / [거부]
- **자동 승인**: 블랙리스트(설교/축도/큐티/브이로그 등) + 문장형 휴리스틱(`...습니다`로 끝나는 제목) 통과 항목 일괄 승인
- **제목 재파싱**: parser 개선 시 PENDING 항목의 `parsed_song_title` 일괄 재계산 (재파싱 후 자동 승인 다시 돌리는 흐름)
- 일괄 처리(approve/reject 배열) / 내보내기(JSON)
- 유튜브 링크로 직접 확인 가능

## 자동화 로드맵
```
현재 (MVP)              → 추후 자동화
───────────────────────────────────
관리자가 채널 등록        → 인기 채널 자동 추천
크롤링 수동 실행         → 주기적 자동 크롤링 (cron)
검증 큐 수동 승인        → AI 자동 매칭 (유사도 기반)
가사 수동 입력           → 유튜브 자막 자동 추출
악보 수동 업로드         → AI 채보 자동 생성
```
